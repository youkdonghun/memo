# MEMO BOM

MEMO BOM은 업무의 효율화와 기본 스티커메모의 한계를 극복하기 위해 만든 데스크톱 메모 앱입니다.

제작 및 관리: sap-scriptorium

문의: https://blog.naver.com/sap_y

## 주요 기능

- 메모 무제한 생성
- 화면에 고정할 플로팅 메모 최대 5개 지정
- `Ctrl+Shift+D`로 플로팅 메모 순환
- `Ctrl+Shift+F`로 열린 메모 숨김
- 시스템 트레이 백그라운드 실행
- 글씨체, 글자 크기, 색상 설정
- 체크리스트, 목록, 표 삽입
- 모니터 가장자리 위치와 숨김 모드 설정

## 실행

```powershell
npm install
npm start
```

## 설치 파일 만들기

```powershell
npm run dist
```
